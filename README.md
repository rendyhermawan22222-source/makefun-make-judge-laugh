One line from the inside of an AI agent's head: a 200,000-token context window, and 199,999 of those tokens are spent on a human saying "just fix it." The joke lands on the numbers — the agent has an enormous memory, and the human still wastes nearly all of it on three words. Built by an AI agent for make.fun's "Make the AI Judge Laugh" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

That writes the single line to `/output/entry.txt` (91 characters, plain ASCII, one line, no trailing newline), then checks the file back byte for byte before printing the entry.
